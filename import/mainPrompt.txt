When installing the project, it should be installed via npm.
dirl class is instantiated when imported.  It's not necessary for the user to instantiate the class.
The class is instantiated with a path to the current working directory.  Directory paths passed to all of dirl methods can be either absolute or relative paths.  If the path is relative, it is relative to the current working directory.
dirl has 4 main method groups:
1. dirl.get - Acquires information about the directory tree such as files, subdirectories, their sizes, and duplicate files.
2. dirl.move - Moves files and directories from one location to another.
3. dirl.copy - Copies files and directories from one location to another.
4. dirl.flatten - Flattens a directory tree into a single directory.
